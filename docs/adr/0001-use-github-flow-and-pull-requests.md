# 0002. Структура модуля перевірки вхідних даних validator.js

- **Статус:** Прийнято
- **Дата:** 2026-11-27
- **Учасники:** Команда проєкту `team-pr-practice`

## Контекст
У проєкті потрібно перевіряти вхідні дані (зокрема формат email) і підтримувати цей код у зрозумілому та легкому для перевірки стані.

## Рішення
Ми виносимо логіку валідації вхідних даних в окремий файл `validator.js` замість того, щоб розкидати перевірки по різних місцях або змішувати їх із документацією.

## Наслідки
- **Плюси:** простіше знаходити, оновлювати та перевіряти правила валідації в одному місці.
- **Мінуси:** для розширення правил перевірки потрібно підтримувати та оновлювати цей модуль узгоджено з вимогами.
